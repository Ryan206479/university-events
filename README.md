# دليل فعاليات الجامعة - مشروع BWP401

موقع متكامل من 5 صفحات بهوية بصرية احترافية (بنفسجي ملكي + برتقالي مرجاني).

## 🎨 الهوية الجديدة
- **الأساسي**: بنفسجي عميق `#4527a0` ← `#7e57c2`
- **المميّز**: برتقالي/مرجاني `#f97316` ← `#ec4899`
- ظلال متعددة الطبقات + تدرّجات احترافية + Glassmorphism في الـ Navbar.

## 📁 الهيكل
```
university-events/
├── index.html          الرئيسية + سلايدر + تصنيفات + كروت
├── events.html         قائمة + فلترة (بحث + تصنيف + شهر)
├── event.html          تفاصيل + معرض + خريطة + Modal تسجيل
├── about.html          رؤية + فريق + Accordion سياسات
├── contact.html        نموذج + تحقق JS + Bootstrap Alerts
└── assets/
    ├── css/styles.css  نظام تصميم كامل + Dark Mode + Responsive
    ├── js/main.js      Theme + Filter + Validation + Scroll-top
    └── img/
```

## ✨ ميزات Bonus
1. **Dark Mode** مع حفظ في localStorage
2. **Scroll-to-top** مع ظهور تدريجي
3. **Modal تسجيل** في صفحة التفاصيل
4. **حفظ التصنيف** عبر sessionStorage بين الصفحات
5. **أضف للتقويم** (.ics download)
6. **Web Share API** لمشاركة الفعالية

## 📝 ملاحظة مهمة
افتح `index.html` وعبّئ أسماءك وأرقامك الجامعية في قسم *"فريق المشروع (BWP401)"*.

## 🚀 التشغيل
